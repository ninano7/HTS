# Industry Insight HTS (산업·포트폴리오 기반 의사결정 시스템)

> **문서 버전**: 1.0 (PRD v1.0 완벽 준수)  
> **제품 형태**: 데스크톱 중심 웹 HTS (16:9 대시보드 레이아웃: 1920×1080 기준, 1366×768 반응형 지원)  
> **핵심 시장**: 한국 상장주식 (KOSPI / KOSDAQ)  
> **4대 핵심 산업**: 철강(Steel), 조선(Shipbuilding), 인공지능(AI), 반도체(Semiconductor)

---

## 1. 개요 및 설계 철학

**Industry Insight HTS**는 가격 변동에만 매몰되거나 평균매수가에 집착하여 투자 논리 훼손을 놓치는 문제를 해결하기 위해 설계된 의사결정 지원 시스템입니다.

1. **좋은 기업과 좋은 매수가격을 구분합니다.**
2. **모든 판단에 근거, 반대 근거, 유효기간, 논리 무효화(Invalidation) 조건을 부여합니다.**
3. **사실(Fact), 계산값(Calculated), 분석적 해석(Interpretation), 사용자 가정(Assumption)을 시각적 배지로 엄격하게 구분합니다.**
4. **시세 누락, 지연, 데이터 오류를 숨기지 않고 불완전 상태(INCOMPLETE)로 명시하여 정직한 의사결정 환경을 제공합니다.**

## 2. 빠른 실행 가이드 (How to Run)

본 시스템은 별도의 외부 무거운 패키지 설치 없이 즉시 실행할 수 있도록 경량 로컬 서버 및 독립 웹 애플리케이션 구조로 제작되었습니다.

### 방법 1. 원클릭 실행 (Windows 권장)
- 작업 폴더 내 **`start-hts.bat`** 파일을 더블클릭합니다.
- 로컬 서버(`http://localhost:3000`)가 구동되며 기본 브라우저가 자동으로 열립니다.

### 방법 2. CLI 실행
```powershell
# 내장 초경량 서버 구동
cmd.exe /c "agy-node.cmd server.js"
# 또는 일반 node 설치 환경인 경우:
node server.js
```
브라우저에서 **`http://localhost:3000`** 으로 접속합니다.

### 방법 3. 브라우저에서 직접 열기
- 로컬 웹 서버 없이도 `index.html` 파일을 브라우저(Chrome, Edge 등)로 바로 열어서 사용하실 수 있습니다.

### 1) 4대 산업 및 대표 16개 종목
- **철강 (Steel)**: POSCO홀딩스(005490), 현대제철(004020), 동국제강(460860), 세아베스틸지주(001430)
- **조선 (Shipbuilding)**: HD한국조선해양(009540), 삼성중공업(010140), 한화오션(042660), HD현대중공업(329180)
- **AI**: NAVER(035420), 카카오(035720), 솔트룩스(304100), 마음AI(377480)
- **반도체 (Semiconductor)**: 삼성전자(005930), SK하이닉스(000660), 한미반도체(042700), 리노공업(058470)
- *복수 테마 태그*: 삼성전자, SK하이닉스는 [반도체] 주 분류와 함께 [AI] 태그를 동시에 표기합니다.

### 2) 조건부 투자 판단 엔진 (Rule Engine)
- 상태 체계: `매수 검토`, `조건 충족 대기`, `보유`, `비중 축소 검토`, `매도 검토`, `판단 유보`
- **신규 진입** vs **기존 보유자** 가이드를 별도로 분리 제공합니다.
- **단기 (1~4주)** vs **중기 (3~12개월)** 시계열 분리 분석을 나란히 제공합니다.
- 논리 무효화 조건(Invalidation Criteria)이 촉발되면 즉시 매도 검토 및 진입 보류로 상태를 자동 전이합니다.
- 유효기한(`validUntil`)이 경과한 근거는 즉시 `판단 유보`로 전환하여 재검토를 유도합니다 (AC-10).

### 3) 포트폴리오 평가 및 시뮬레이터
- **포트폴리오 평가**: 총매입원가, 평가금액, 미실현손익, 단순수익률, 현금, 총자산, 비중, 손익기여도를 실시간 산출합니다.
- **불완전 상태 안내**: 시세 누락 종목이 있으면 확정 합계로 단정하지 않고 `불완전(INCOMPLETE)` 경고를 표시합니다 (AC-06).
- **가상 매매**: 가상 매수/매도 시 원본 보유현황은 절대 변경하지 않고, 조정 후 자산·비중·현금 변화를 비교합니다 (AC-04). 보유 수량 초과 매도는 차단됩니다 (AC-05).
- **손실 예산 계산기**: 허용손실액과 진입가, 손절가를 입력하면 진입 가능한 정수 주수를 공식(`floor`)에 맞춰 정확히 계산합니다 (AC-11).
- **가격 충격 스트레스 테스트**: 개별 종목 또는 업종 -10%, -20% 급락 충격 시 내 계좌의 자산 감소액을 시뮬레이션합니다.

### 4) CSV/XLSX 업로드 및 백업/복원
- **템플릿 제공**: `templates/holdings_template.csv` 기본 제공.
- **종목코드 앞자리 0 보존**: "005930" 등이 문자열로 엄격하게 보존됩니다 (AC-01).
- **중복 처리**: 수량가중 평균단가 합산(AC-02), 덮어쓰기, 건너뛰기 지원.
- **오류 행 분리**: 오류 행 발생 시 구체적인 사유 안내 및 오류 행만 `.csv`로 다운로드 가능합니다 (AC-13).
- **JSON 전체 백업/복원**: `schema_version` 검증 및 복원 전 임시 스냅샷 자동 생성으로 롤백을 보장합니다 (AC-14).
- **인쇄 최적화**: 브라우저 인쇄 단축키(Ctrl+P) 또는 [🖨️ 인쇄·PDF] 버튼 클릭 시 A4 가로 최적화 보고서가 출력됩니다 (AC-15).
